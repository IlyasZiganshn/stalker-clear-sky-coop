# gamedata

Только **наш** Lua-слой. Никаких файлов из оригинальной игры, никаких распакованных
архивов GSC, никаких ассетов — см. правовую рамку в корневом `README.md`.

## Что здесь будет

```
gamedata/scripts/coop/
  main.script          точка входа, инициализация по флагу сервера/клиента
  net.script           мост Lua ↔ движковый netcode
  rpc.script           таблица RPC и маршалинг аргументов
  story.script         обёртка task_manager: зеркало задач, блокировка диалогов
  dialogs.script       перехват диалогов
  world.script         faction war, точки, отношения группировок
  level.script         переходы уровней, двухфазная загрузка
  ui.script            лобби, чат, список игроков, уведомления
  debug.script         отладочные команды, диагностика рассинхрона
```

Принцип: скрипты Clear Sky не переписываем, а оборачиваем. Всё, что меняет мир,
исполняется на сервере; клиент получает состояние и рисует.

## Правила

- Новая логика — только в файлах `coop/*`. Правка оригинальных `.script` — через
  патч в `engine/patches/` с обоснованием.
- Никаких жёстко прописанных путей к установленной игре.
- Каждый RPC описывается декларативно (типы аргументов), таблица генерируется
  на этапе M4 — не поддерживается руками.
