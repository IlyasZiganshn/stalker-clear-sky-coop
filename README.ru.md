# Stalker Clear Sky: Coop

**[English](README.md) | [Русский](README.ru.md)**

Кооперативная платформа для совместного прохождения сюжетной кампании **S.T.A.L.K.E.R.: Clear Sky 1.5.10** (2–4 игрока), построенная на собственном сетевом слое `coopnet` (C++20 / UDP), наборе патчей к **OpenXRay**, синхронизированном Lua-слое и отдельном лаунчере **Clear Sky Tactical PDA** для Windows.

---

## Обзор и возможности

| Компонент | Назначение |
|---|---|
| `coopnet/` | Автономная библиотека C++20: UDP-транспорт, надёжные/ненадёжные каналы, рукопожатие, дельта-снапшоты, измерение RTT, предсказание движения и интерполяция акторов. |
| `engine/` | Воспроизводимая очередь патчей (`engine/patches/*.patch` + `engine/patches/files/`) поверх зафиксированного коммита OpenXRay (`engine/upstream.txt`). |
| `gamedata/scripts/` | Кооперативные Lua-скрипты: синхронизация заданий (`coop_tasks.script`), блокировка диалогов (`coop_dialogs.script`), кат-сцены (`coop_cutscenes.script`) и внутриигровое лобби (`coop_lobby.script`). |
| `launcher/` | Лаунчер на C# WinForms (`ClearSkyCoopLauncher.exe`) с 4 вкладками (`Lobby & Radar`, `Host Campaign`, `Mod & Config`, `Diagnostics`), поиском серверов в LAN, установкой мода и сбором диагностики. |
| `tools/` и `scripts/` | Симулятор сети (`net_sim`), автономные тесты `coopnet`, сборщик релизов и автотесты с запуском двух окон игры. |

### Основные реализованные возможности
- **Авторитарный сервер (Host)**: прямое UDP-подключение, автоматический спавн напарников, интерполяция позиций и анимаций, проверка совпадения уровня.
- **Кооперативное взаимодействие**: напарник на миникарте и в мире (ник и индикатор здоровья), ослабленный урон по своим, подъём раненого союзника, общая синхронизация сюжетных заданий, инфопоршней, диалогов и кат-сцен.
- **Внутриигровое предыгровое лобби (`coop_lobby.script`)**: выбор облика (скина) персонажа выполняется **непосредственно внутри игры** (не в лаунчере), после чего каждый игрок нажимает **`Ready`**. Смена скина сбрасывает статус **`Ready`**. Если на хосте есть сохранение — отображается только кнопка **`Continue`**; если сохранений нет — отображаются обе кнопки **`Continue`** и **`New Game`**. Хост не может начать матч, пока все игроки не нажмут **`Ready`**.

## Правовая рамка и требования

- **Репозиторий не содержит оригинальных ресурсов GSC Game World.** Игровые архивы (`.db*`/`.xdb`), текстуры, модели, уровни и звуки не распространяются.
- Для игры каждому участнику требуется **лицензионная копия S.T.A.L.K.E.R.: Clear Sky (версия 1.5.10, Steam / GOG / диск)**.
- Проект является некоммерческой фанатской модификацией в соответствии с [Fan Content Creation Guidelines](https://www.gsc-game.com/guidelines/) GSC Game World.

### Системные требования
- **ОС**: Windows 10 / 11 (64-bit)
- **Игра**: S.T.A.L.K.E.R.: Clear Sky 1.5.10
- **Сеть**: локальная сеть (LAN), виртуальная сеть (Radmin VPN, ZeroTier, Hamachi, WireGuard) или проброс портов (`27016` UDP / `27015` UDP broadcast)

## Установка и запуск (для игроков)

1. Распакуйте релиз мода (или соберите из исходников по инструкции ниже).
2. Запустите **`ClearSkyCoopLauncher.exe`**.
3. На вкладке **Mod & Config** проверьте путь к установленной игре S.T.A.L.K.E.R.: Clear Sky и выполните развёртывание файлов мода.
4. **Хост (Создатель игры)**: откройте вкладку **Host Campaign**, укажите имя игрока, название сервера и UDP-порт (`27016`), нажмите **Start Host**.
5. **Клиент (Напарник)**: на вкладке **Lobby & Radar** выберите сервер хоста в списке LAN (или введите IP и порт вручную) и нажмите **Join**.
6. Во **внутриигровом лобби** каждый игрок выбирает скин и нажимает **`Ready`**. Когда все игроки готовы, хост нажимает **`Continue`** или **`New Game`**.

Подробная инструкция для игроков: [docs/INSTALL.md](docs/INSTALL.md).

## Сборка и тестирование из исходников

### 1. Сборка и тестирование `coopnet` (без установленной игры)
Требуются **Visual Studio 2022 / Build Tools** (MSVC C++20), **CMake >= 3.25** и **Ninja**:

```powershell
./scripts/build.ps1 -Test
```

Команда собирает библиотеку `coopnet`, утилиты (`coopnet_tests`, `coopnet_echo`, `coopnet_snap`, `coopnet_move`, `coopnet_chat`, `coopnet_world`, `coopnet_spawn`, `net_sim`) и прогоняет тесты `ctest`.

### 2. Сборка и проверка лаунчера
Требуется .NET Framework 4.8 / Roslyn `csc.exe`:

```powershell
./launcher/build.ps1
./ClearSkyCoopLauncher.exe --test-lobby
```

### 3. Сборка пропатченного движка OpenXRay
```powershell
./engine/fetch.ps1   # скачивает зафиксированный коммит OpenXRay в engine/src/
./engine/apply.ps1   # копирует coopnet/ + engine/patches/files/ и применяет патчи
./engine/build.ps1   # восстанавливает зависимости и собирает Release x64
```

Подробнее о сборке: [docs/BUILD.md](docs/BUILD.md) и [engine/README.md](engine/README.md).

```text
.
├── .github/workflows/   GitHub Actions CI (тесты coopnet + сборка и тест лаунчера)
├── coopnet/             Автономная библиотека C++20 (сетевой транспорт, снапшоты, тесты)

```
