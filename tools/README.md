# tools

Инструменты разработки и диагностики.

Сейчас есть:

| Инструмент | Назначение |
|---|---|
| `coopnet_selftest` | стресс-тест надёжного канала: 40 сообщений, 30% потерь, порядок |
| `coopnet_echo` | рукопожатие и эхо событий через реальный UDP, печатает RTT и байты |
| `coopnet_snap` | репликация мира: сервер шлёт дельты снапшотов, клиент подтверждает и применяет |

Планируется:

| Инструмент | Этап | Назначение |
|---|---|---|
| `snapshot_dump` | M1 | разбор дампа снапшота в человекочитаемый вид |
| `net_log` | M1 | запись и воспроизведение трафика сессии |
| `net_sim` | M1 | имитация задержки/потерь/джиттера для тестов |
| `dedicated` | M2 | запуск сервера без игрока (обёртка над headless-режимом) |
| `replay` | M6 | разбор реплея рассинхрона |
